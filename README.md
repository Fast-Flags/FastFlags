## ⚙️ Commands

<table>
<tr><td width="50%">

### ✅ `/validatelist`
Checks for invalid & outdated flags in your list.
- 📄 Supports JSON and JSONC
- 🔄 Detects newer replacement flags
- 📃 Allowlist Supported

</td><td width="50%">

### 🔍 `/informationflag`
Checks an FFlag and shows its functions & features.
- 📝 Comma-separated for multiple flags

</td></tr>
<tr><td width="50%">

### 🔄 `/convertjson`
Converts keys/values into JSON format.
- ✨ Comma-separated multi-key support
- ✅ JSON ↔ INI conversion
- ✅ AppleBlox JSON compatible

</td><td width="50%">

### 🌍 `/checkservers`
 - Shows all the servers that the bot is in with additional information.

</td></tr>
<tr><td width="50%">

### 🔎 `/findflag`
Find a specific flag by keyword.
- ⚠️ Toggle to disable Studio FFlags
- 🔢 Commas/spaces for multiple keywords
- 🔗 Use `&` to search multiple FFlags separately

</td><td width="50%">

### 🔗 `/mergejson`
Merges 2 flag sources together.
- 🔗 Combine two FFlag lists or blocks of text

</td></tr>
<tr><td width="50%">

### 🎰 `/randomflag`
Rolls random flags (default: 25).
- 📜 Pick file source(s)
- ❔ Filter by FastFlag type
- 🔢 Set custom amount

</td><td width="50%">

### ✨ `/newfflags`
Lists flags discovered in the last 24 hours.
- 🔔 Stay on top of every update

</td></tr>
<tr><td colspan="2">

### 👏 `/credits`
Shows credits for everyone who made this bot possible. 🙌

</td></tr>
</table>

## 📊 Trackers

| Tracker | What it watches |
|---|---|
| 🚀 **Deployment Tracker** | Updates across all Roblox platforms |
| 🧪 **Build Tracker** | Roblox testing channels (e.g. **ZBeta**) |
| 🏷️ **Version Tracker** | Main production channel updates |
| 📜 **Flog Tracker** | Roblox FLog archives — how Roblox tracks changes now |
| 🎨 **SpriteSheets Tracker** | Pictogram changes — useful for modders |
| 🌦️ **Shader Tracker** | Tracks the Roblox Shader Configuration |
| 🌳 **C++ Tracker** | Tracks the C++ structure of Roblox |
